# Brand Asset AI Studio

A사 제공 3D 에셋과 디자인팀의 승인 에셋을 기준으로, 일관된 톤앤매너의 새 에셋을 만드는 웹앱의 **Phase 1 UI 프로토타입**입니다. React + TypeScript + Vite로 구현했습니다.

**현재 이미지 분석 및 OpenAI 이미지 생성 API는 연결되어 있지 않습니다.** 기본 이미지, 생성 결과, 분석 결과, 승인 표시는 UI 검증용 데모입니다. A사에서 제공하거나 실제로 승인한 자료가 포함되어 있지 않습니다.

## 구현 범위

| 화면                 | 실제 동작하는 Phase 1 기능                                                                          |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| AI 에셋 생성         | 키워드 입력·검증, 추천 키워드, 프로필 선택, 로딩 상태, 데모 결과 미리보기, PNG 다운로드             |
| 승인 에셋 라이브러리 | 이미지 목록·상세, 검색, 카테고리·승인 상태 필터, 파일 선택·드래그 업로드, 로컬 승인 상태 변경, 삭제 |
| 브랜드 스타일 관리   | 활성 프로필, 예시 분석, 소재·조명·구도·팔레트와 공통 규칙 조회                                      |
| 생성 히스토리        | 키워드·이미지·프로필·시간 기록, 상세 보기, 키워드 재사용, 개별 삭제                                 |
| 관리자 설정          | 프로필 추가·편집·활성화·삭제, 연동 상태 표시, JSON 백업, 확인 후 데모 초기화                        |

데스크톱과 모바일 레이아웃, 키보드 포커스, 모달의 포커스 제한·Escape 닫기, 입력 오류 및 빈 목록 상태를 지원합니다. 폰트와 데모 일러스트는 앱에 포함되어 외부 CDN이 필요하지 않습니다.

## 실행

Node.js **22.12 이상**이 필요합니다. 현재 클라우드 환경에서는 Node.js 24로 확인했습니다.

```bash
cd /workspace/jop_app
npm ci --cache /workspace/.cache/npm
npm run dev
```

`npm ci`로 의존성을 재설치한 경우 실행 중이던 개발 서버를 종료하고 다시 시작하세요. Vite의 이전 의존성 캐시가 남으면 화면이 비어 보일 수 있습니다.

개발 서버는 모든 인터페이스의 **5173 포트**를 사용합니다. 기존 클라우드 환경을 그대로 사용하며 새 환경을 만들 필요가 없습니다. 다른 컴퓨터에서는 저장소를 받은 디렉터리에서 `npm ci`와 `npm run dev`를 실행하면 됩니다.

미리보기 방법:

- 로컬 실행 시 브라우저에서 개발 서버의 5173 포트를 열어 확인합니다.
- 포트 전달을 지원하는 개발 도구에서는 5173 포트를 전달해 확인할 수 있습니다.
- 현재 클라우드 온보딩 화면은 웹앱 미리보기 링크를 제공하지 않습니다. 아래 스크린샷으로 화면을 검토할 수 있습니다.
- 정적 배포가 필요하면 `npm run build`로 생성한 `dist/`를 정적 호스팅에 배포합니다. 현재 외부 배포는 수행하지 않았습니다.

프로덕션 빌드 실행:

```bash
npm run build
npm run preview -- --port 4173 --strictPort
```

## 테스트

```bash
npm test                   # 입력 검증, 데모 서비스, 저장 데이터 검증, 업로드 제한
npm run test:e2e           # 실제 Chromium 사용자 흐름
npm run build             # TypeScript 검사 + 프로덕션 번들
npm run format:check      # 소스 포맷 확인
```

클라우드에 설치된 `/usr/bin/chromium`을 E2E 테스트에서 사용합니다. 별도 머신에서는 먼저 `npx playwright install chromium`을 실행하세요. 다른 Chromium 실행 파일은 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 지정할 수 있습니다.

E2E 테스트는 개발 서버가 없으면 자동 시작합니다. PNG 파일의 시그니처와 800×800 해상도, 업로드 후 승인 대기 상태, 명시적 승인, 새로고침 후 저장 상태, 프로필 규칙 변경, 기록 재사용·삭제, JSON 백업·초기화, 390px 모바일에서 5개 화면의 가로 넘침, 손상된 저장 데이터 복구를 검증합니다. 생성 흐름이 외부 API나 CDN을 호출하지 않는 것도 확인합니다.

스크린샷 재생성은 서버를 실행한 상태에서 `npm run screenshots`를 사용합니다. 기본 대상 포트는 5173이며 `STUDIO_BASE_URL`로 테스트 대상 서버를 바꿀 수 있습니다.

## 데이터와 데모의 경계

- **생성:** `generateDemo()`는 키워드를 6개의 번들 SVG 일러스트 중 하나에 매핑합니다. 새로운 AI 이미지를 생성하지 않습니다. 업로드한 이미지나 변경한 스타일 규칙은 결과 이미지에 반영되지 않습니다. 다운로드는 이 일러스트를 PNG로 변환합니다.
- **분석:** `Soft Dimension`의 분석 값은 사전 정의된 예시입니다. 이미지 분석 점수나 실제 분석 성공 여부를 꾸며내지 않습니다.
- **라이브러리:** 기본 샘플의 `A사 제공`·`디자인팀 제작` 출처와 승인 상태는 데모 분류입니다. 사용자가 업로드한 이미지는 `UPLOAD`와 `승인 대기`로 구분합니다. 승인 처리도 로컬 상태 변경이며 실제 검수 절차가 아닙니다.
- **저장:** `localStorage`의 `brand-asset-studio:phase1:v1`에 현재 브라우저의 데이터만 저장합니다. 로그인, 관리자 권한, DB, 서버 업로드, 다른 기기와의 동기화는 없습니다. 저장이 차단되거나 공간이 부족하면 경고를 표시합니다.
- **업로드 제한:** PNG/JPG/WebP, 파일당 5MB·4,000만 픽셀 이하, 최대 12개. 로컬 저장을 위해 최대 480px PNG로 축소하고 450KB 미만의 데이터 URL만 허용합니다. 원본 파일 보관 기능이 아닙니다.
- **보관 제한:** 생성 기록 최대 40개, 스타일 프로필 최대 5개. 브라우저 데이터를 지우면 내용이 사라집니다. JSON 백업은 내보내기만 제공하며 가져오기 UI는 Phase 1 범위에 포함하지 않습니다.
- **이미지 소스:** `public/assets/`의 SVG 6개는 이 프로토타입을 위해 코드로 만든 자체 일러스트입니다. 실제 3D 모델 파일이 아닙니다.

## 구조와 후속 연동 지점

```text
src/
  App.tsx               # 5개 화면과 로컬 상태·사용자 흐름
  components.tsx        # 공통 헤더, 데모 표시, 접근성 모달, 빈 상태
  types.ts              # Asset, Generation, Profile, StudioState 계약
  data.ts               # 명시적으로 구분된 샘플 에셋·스타일·기록
  services/studio.ts     # 데모 생성 어댑터, 입력/저장 검증, 이미지 입출력
  services/studio.test.ts
  styles.css            # 반응형 SaaS UI
public/assets/          # 로컬 데모 일러스트
tests/e2e/              # 실제 브라우저 기능 검증
docs/                   # 구현 결과와 스크린샷
```

후속 Phase에서는 `services/studio.ts`의 데모 생성 어댑터를 인증된 백엔드 호출로 교체하고, 업로드 원본 저장·실제 A사 승인 워크플로·이미지 분석·스타일 버전·비동기 이미지 생성 작업을 연결할 수 있습니다. OpenAI API 키는 브라우저나 `VITE_*` 변수에 넣지 않고 백엔드에서 관리해야 합니다. 이번 구현에는 API 키 설정이나 실제 과금 요청이 없습니다.
